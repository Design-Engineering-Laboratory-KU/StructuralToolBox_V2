# Structural Toolbox — インストール（Windows / Mac）

**Python のインストールは不要**です。受け取ったインストーラを開くだけです。解析ライブラリも同梱されているので、**インターネットも不要**です。

---

## 用意するもの

| | Windows | Mac |
| --- | --- | --- |
| OS | **Windows 10 / 11**（64 ビット） | **macOS 12 以降**（Apple シリコン / Intel のどちらでも可） |
| 空きディスク | 約 1 GB | 約 1 GB |

---

## 1. インストール（初回だけ）

### Windows

1. **`StructuralToolbox_Setup_X.Y.Z_YYYYMMDD.exe`** をダブルクリックする。
2. 画面の指示に従う（インストール先はそのままで問題ありません。変える場合は、パスが 100 文字以内の場所にしてください）。
3. 「ライブラリをセットアップしています」と表示されたら、**完了まで待つ**（2〜5 分）。
4. 完了メッセージを読んでウィザードを閉じる。

**黒い画面が一瞬出ることがあります** — セットアップ用です。操作は不要です。

### Mac

配布の形は次のいずれかです。中身の操作は同じです。

| 受け取ったファイル | 最初にすること |
| --- | --- |
| `StructuralToolbox_Setup_Mac_X.Y.Z_YYYYMMDD.pkg` | ダブルクリックして、画面の指示に従う |
| `StructuralToolbox_Mac_X.Y.Z_YYYYMMDD.dmg` | 開き、中の **`インストール.command`** を右クリック → **開く** |
| `StructuralToolbox_Mac_Setup_X.Y.Z_YYYYMMDD.tar.gz` | ダブルクリックで展開し、フォルダ内の **`インストール.command`** を右クリック → **開く** |

`インストール.command` のとき:

1. 初回は「開発元を確認できません」と出ることがあります。**開く** を選んでください。
2. 「インストール」を押す。
3. ターミナルに「ライブラリをインストールしています」と出たら、**完了まで待つ**（2〜5 分）。
4. 「インストールが完了しました」と出たら閉じてよいです。

**.pkg** のときも、セットアップが終わるまで待ちます。管理者パスワードは不要です。

### 新しいバージョンに入れ替えるとき

アンインストールせずに、新しいインストーラをそのまま実行してください。以前のバージョンは自動で削除され、同梱の Python も含めて入れ直されます。

- インストール先に自分で保存した **`.dat` / `.out` / `.gh` / `.ghx`**（と `.dat` に付く `.project.json`）は残ります。
- 配布物に入っている例題（`examples` などの `.dat`）は、新しいものに置き換わります。例題を書き換えて使っている場合は、先に別の名前で保存してください。
- Windows でインストール先を前回と変えた場合は、前回のフォルダにあった上記のファイルを新しいインストール先へ移し、前回のフォルダは削除します。同じ名前のファイルがあるときは `（名前） (old 1).dat` のように名前を変えて残します。
- Structural Toolbox を起動したままだと、「以前のバージョンを削除できませんでした」と出て止まります。終了してから実行し直してください。

## 2. 毎回の使い方

| | Windows | Mac |
| --- | --- | --- |
| 起動するもの | **スタートメニュー** または **デスクトップ** の **「Structural Toolbox」** | **デスクトップ** または **アプリケーション** フォルダの **「Structural Toolbox」** |
| 開く画面 | **黒い画面（コマンドプロンプト）** | **ターミナル** |

1. 「Structural Toolbox」を開く。
2. 黒い画面（Mac はターミナル）が開き、しばらくすると **ブラウザ** が開く。
3. モデル（.dat）を選び、**Solve** で解析する。
4. 終了するときは、**黒い画面（Mac はターミナル）のウィンドウを閉じる**。

**解析中はこの画面を閉じないでください**（ログとサーバーがここで動きます）。

### デバッグ・ログを見たいとき（開発向け）

- Windows: スタートメニューの **「Structural Toolbox (debug)」**、またはインストール先の **`Start Structural Toolbox (debug).bat`** を使う。コンソールが残ります。
- Mac: アプリケーションフォルダの **「Structural Toolbox (debug)」** を使う。
- どちらも、インストール先に **`stb_gui.log`** が保存されます。

## 3. インストール先と最初に試すモデル

| | インストール先 | 開き方 |
| --- | --- | --- |
| Windows | `C:\Users\（あなたの名前）\AppData\Local\StructuralToolbox` | エクスプローラーのアドレス欄に `%LOCALAPPDATA%\StructuralToolbox` と入力 |
| Mac | `~/Library/Application Support/StructuralToolbox` | Finder の「移動」→「フォルダへ移動」に、左のパスを貼り付ける |

最初に試すモデル:

| モデル | 説明 |
| --- | --- |
| `examples/cantilever.dat` | いちばん簡単な片持ち梁 |

（インストール先の `examples` フォルダにあります。）

## 4. よくあるトラブル

| 症状 | 対処 |
| --- | --- |
| インストールが途中で失敗 | インストーラ（Windows は Setup.exe、Mac は `インストール.command` または .pkg）を再実行。直らない場合はインストール先の **`install.log`** を配布元に見せる |
| ブラウザが開かない | ショートカットを再実行。`http://127.0.0.1:8765/` を手で開く |
| 「インストール先のフォルダのパスが長すぎます」 | Windows は、パスが 260 文字を超える DLL を読み込めません。パスが 100 文字以内のフォルダ（例: `C:\Users\（あなたの名前）\StructuralToolbox`）にインストールし直す |
| Grasshopper で「Structural Toolbox Python was not found」 | インストール先を変えた場合は、スタートメニューの **「初回セットアップを再実行」** を一度実行する（プラグインにインストール先を知らせます） |
| 「初回セットアップがまだ」 / stb.exe がない | Windows はスタートメニューの **「初回セットアップを再実行」**、Mac はインストール先の **`Install_once.command`** を実行（2〜5 分待つ） |
| ショートカットが stb.exe を探す（Windows） | 新しい Setup.exe で再インストールするか、ショートカットの代わりにフォルダ内の **Start Structural Toolbox.bat** を実行 |
| 「開発元を確認できません」（Mac） | 右クリック → **開く**。またはターミナルで `bash インストール.command` |
| Solve でエラー | 配布元に `.dat` の行番号とメッセージを伝える |

### 専用の Python が使われているか確かめる

起動時の画面に、次の表示があれば専用の Python が使われています。

- Windows: `python: ...\StructuralToolbox\.venv\Scripts\python.exe (bundled)`
- Mac: `python: ~/Library/Application Support/StructuralToolbox/.venv/bin/python3 (bundled)`

コマンドで確かめる場合:

- Windows: エクスプローラーのアドレス欄に `%LOCALAPPDATA%\StructuralToolbox` を入れて開き、アドレス欄に `cmd` と入力して Enter。開いた画面で次を実行します。

  ```
  .venv\Scripts\stb.exe doctor
  ```

- Mac: ターミナルで次を実行します。

  ```bash
  "$HOME/Library/Application Support/StructuralToolbox/.venv/bin/stb" doctor
  ```

`bundled: yes` と、ライブラリの一覧が表示されれば正常です。

## 5. Grasshopper を使う場合

インストール時に、プラグイン `StbGrasshopper.gha` を Grasshopper のライブラリフォルダへ自動で配置します。

| | 配置先 |
| --- | --- |
| Windows | `%APPDATA%\Grasshopper\Libraries` |
| Mac（Rhino 8） | `~/Library/Application Support/McNeel/Rhinoceros/8.0/Plug-ins/Grasshopper (b45a29b1-4343-4035-989e-044e8580d9cf)/Libraries` |

- Rhino を起動中だった場合は、Rhino を終了してから、Windows はスタートメニューの **「初回セットアップを再実行」**、Mac は `Install_once.command` を実行する
- STB コンポーネントの **Python Exe** と **Repo Root** は **空のまま**でよい（インストール先の専用 Python を自動で使います）
- 解析後、コンポーネントの **Summary** に使われた Python のパスが表示されます

## 6. アンインストール（削除）

削除の前に、動いている **黒い画面（Mac はターミナル）のサーバーを閉じて** ください。インストール先に保存したモデルは消えることがあるので、必要な `.dat` は先に別の場所へコピーしてください。

### Windows

スタートメニューの **「Structural Toolbox をアンインストール」** を実行します。見つからない場合は、次のいずれかで削除できます。

1. **Windows の設定** → **アプリ** → **インストールされているアプリ** → **Structural Toolbox** → **アンインストール**
2. エクスプローラーのアドレス欄に次を貼り付けて Enter → **`unins000.exe`** をダブルクリック:
   ```
   %LOCALAPPDATA%\StructuralToolbox
   ```

### Mac

アプリケーションフォルダの **「Structural Toolbox をアンインストール」** を実行します。

手動で消す場合は、次の 3 つを削除します。

- `~/Applications/Structural Toolbox.app`
- `~/Desktop/Structural Toolbox`
- `~/Library/Application Support/StructuralToolbox`

## 7. やらなくてよいこと

- python.org から Python を入れる
- Git やコマンドの手入力（Mac で右クリックから開けないときの `bash インストール.command` を除く）
- インストール先フォルダ内の次のフォルダを削除する（削除すると再セットアップが必要）
  - Windows: `python-embed`、`wheels`、`.venv`
  - Mac: `python-standalone-*`、`wheels`、`.venv`

## 付録. Windows で ZIP 版を受け取った場合

ZIP 版（例: `StructuralToolbox_Windows_X.Y.Z_YYYYMMDD.zip`）も、中身は Setup.exe と同じです。Python とライブラリが同梱されているので、インターネットは不要です。
ZIP 版では、**ZIP を解凍したフォルダがインストール先**になります。3〜5 章の「インストール先」は、このフォルダに読み替えてください。

### A-1. ZIP の解凍

1. ZIP を解凍する。
2. **ローカルディスク**（`C:\Users\...\Documents` など）に置く。Dropbox 直下は同期の競合を避けるため非推奨。
3. 次のものが **同じフォルダの直下** にあることを確認する:
   - `Install_once.bat`
   - `Start Structural Toolbox.bat`
   - `python-embed` フォルダ（同梱 Python）
   - `examples` フォルダ

**注意:** ZIP の中に `StructuralToolbox_Windows_...` のようなフォルダが 1 段入っていることがあります。その **中** で `.bat` を実行してください。

### A-2. 初回だけ — セットアップ

1. **`Install_once.bat`** をダブルクリックする。
2. 黒い画面に文字が流れる（2〜5 分）。
3. 「セットアップ完了」と表示されたら、何かキーを押して閉じる。

このとき、同梱の **Python 3.12**（`python-embed`）でこのフォルダ専用の **`.venv`** を作り、ライブラリをインストールします（自動・操作不要）。
**PC にもともと入っている Python は使いません。** 他の授業用 Python と混ざりません。

### A-3. 毎回の使い方

1. **`Start Structural Toolbox.bat`** をダブルクリックする。
2. しばらくすると **ブラウザ**（Chrome / Edge など）が開く。
3. 画面上部で **モデル（.dat）** を選び、**Solve** で解析する。
4. **Results** タブで変形・部材力などを確認する。
5. 終了するときは、黒い画面で **Ctrl+C** を押すか、その画面を閉じる。

受け取った `.dat` は、解凍したフォルダ内の `examples` などにコピーします。一覧に出ない場合は、一度終了してから起動し直してください。

### A-4. ZIP 版のトラブル

| 症状 | 対処 |
| --- | --- |
| 「同梱の Python が見つかりません」 | ZIP を解凍し直す。`python-embed` フォルダがある階層で実行 |
| 「初回セットアップがまだ」 / インストール失敗 | `Install_once.bat` を再実行 |
| `No module named venv` | 古い ZIP の可能性あり。新しい ZIP を入手し、フォルダごと入れ替えて `Install_once.bat` を再実行 |
| ウイルス対策がブロック | 配布元に相談（フォルダの除外設定など） |

ほかの症状は「4. よくあるトラブル」を見てください。

### A-5. 削除

黒い画面を閉じてから、解凍したフォルダごと削除します。Grasshopper のプラグインは `%APPDATA%\Grasshopper\Libraries\StbGrasshopper.gha` に残るので、不要なら別に削除してください。
