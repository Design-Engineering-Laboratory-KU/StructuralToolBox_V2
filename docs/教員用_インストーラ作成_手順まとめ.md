# 教員用 — Windows / Mac インストーラ作成手順（確定版）

2026-09-29〜10-01 に実際にビルド・インストールまで通した手順です。
途中で起きたエラーとその対策も最後にまとめています。

学生側は **インターネット不要** でインストールできます（Python 本体と解析ライブラリをすべて同梱）。
Grasshopper プラグイン `StbGrasshopper.gha` も自動でライブラリフォルダへ配置されます。

---

## 0. 準備（Windows のビルド機）

| 必要なもの | 用途 |
| --- | --- |
| Windows 11 + PowerShell | ビルド |
| `py -3`（Python 3.10 以上） | ビルドスクリプトの実行 |
| [Inno Setup 6](https://jrsoftware.org/isdl.php) | Setup.exe の作成 |
| .NET SDK | `.gha` のビルド（毎回自動でビルドし直します） |
| インターネット | **ビルド時のみ**。Python と wheels を取得（`student/dist/_cache/` にキャッシュ） |

ビルド前に:

- **Rhino を終了する**（起動中だと `.gha` のコピーが失敗します）
- リポジトリ直下で PowerShell を開く

---

## 1. Windows 版（Setup.exe）

```powershell
.\student\build_student_zip.ps1
.\student\build_student_installer.ps1 -SourceDir student\dist\_build\StructuralToolbox_Windows_YYYYMMDD
```

出力:

| ファイル | 説明 |
| --- | --- |
| `student\dist\StructuralToolbox_Setup_YYYYMMDD.exe` | **学生に配るのはこれだけ**（約 75 MB） |
| `student\dist\StructuralToolbox_Windows_YYYYMMDD.zip` | 予備（解凍 → `Install_once.bat`） |

### 動作確認（ビルド機で必ず 1 回）

```powershell
$dir = "$env:TEMP\stb_verify"
Start-Process .\student\dist\StructuralToolbox_Setup_YYYYMMDD.exe -ArgumentList "/VERYSILENT","/SUPPRESSMSGBOXES","/DIR=$dir" -Wait
& "$dir\.venv\Scripts\stb.exe" doctor --require-bundled     # bundled: yes ならOK
Test-Path "$env:APPDATA\Grasshopper\Libraries\StbGrasshopper.gha"   # True ならOK
& "$dir\unins000.exe" /VERYSILENT
```

`stb.exe` が無い場合は `$dir\install.log` の最後を確認してください。

> アンインストールすると `%APPDATA%\Grasshopper\Libraries\StbGrasshopper.gha` も消えます。
> 開発機で試したあとは `grasshopper\gha\bin\Release\StbGrasshopper.gha` をコピーし直してください。

### 学生の操作

1. Setup.exe をダブルクリック → ウィザードを進める（2〜5 分）
2. スタートメニュー / デスクトップの **Structural Toolbox** から起動

インストール先: `%LOCALAPPDATA%\StructuralToolbox`（管理者権限不要）

## 2. Mac 版

### 2-1. Windows で tar.gz と .pkg 作成スクリプトを作る

```powershell
.\student\build_student_mac.ps1
```

出力（どちらも Mac に持っていく）:

| ファイル | 説明 |
| --- | --- |
| `student\dist\StructuralToolbox_Mac_Setup_YYYYMMDD.tar.gz` | 本体（約 130 MB）。これ単体でも配布可能 |
| `student\dist\StructuralToolbox_Mac_make_pkg_YYYYMMDD.sh` | Mac で .dmg / .pkg を作るスクリプト（**リポジトリ不要**） |

ビルドの最後に `OK: bundled libraries (38 wheels)` のように表示されます。
**wheels に `uvloop` が含まれていること**が Mac で動く条件です（下の「エラーと対策」参照）。

### 2-2. Mac で .dmg と .pkg を作る

上の 2 ファイルを Mac の同じフォルダ（例: `~/Downloads/try`）に置き、ターミナルで:

```bash
cd ~/Downloads/try
bash StructuralToolbox_Mac_make_pkg_YYYYMMDD.sh
```

`完成: …dmg` と `完成: …pkg` が出れば成功です。同じフォルダに次ができます。

| ファイル | 学生の操作 |
| --- | --- |
| `StructuralToolbox_Setup_Mac_YYYYMMDD.pkg` | **推奨**。ダブルクリック → 「自分専用にインストール」 |
| `StructuralToolbox_Mac_YYYYMMDD.dmg` | 開いて `インストール.command` を右クリック → 開く |
| （tar.gz） | 展開して `インストール.command` を右クリック → 開く |

> 古い `build_student_installer_mac.sh` はリポジトリ全体が Mac にあるときだけ動きます。
> 単体で置くと「build_student_mac.py がありません」になるので、`make_pkg` の方を使ってください。

### 2-3. 動作確認（Mac で必ず 1 回）

既存のインストールを消してから .pkg を試します。

```bash
rm -rf "$HOME/Library/Application Support/StructuralToolbox"
rm -f /tmp/stb-install.log
open ~/Downloads/try/StructuralToolbox_Setup_Mac_YYYYMMDD.pkg
```

完了後:

```bash
"$HOME/Library/Application Support/StructuralToolbox/.venv/bin/stb" doctor --require-bundled   # bundled: yes
ls "$HOME/Library/Application Support/McNeel/Rhinoceros/8.0/Plug-ins/"Grasshopper*/Libraries/StbGrasshopper.gha
```

GUI は `~/Applications`（ホームの「アプリケーション」）またはデスクトップの **Structural Toolbox** から起動します。
ブラウザが開かなければ `http://127.0.0.1:8765/` を開いてください。

### ログの場所（失敗したとき）

| ログ | 絶対パス |
| --- | --- |
| .pkg の postinstall | `/tmp/stb-install.log` |
| 初回セットアップ | `/Users/<ユーザー名>/Library/Application Support/StructuralToolbox/install.log` |
| macOS インストーラ全体 | `/var/log/install.log` |

```bash
cat /tmp/stb-install.log
tail -40 "$HOME/Library/Application Support/StructuralToolbox/install.log"
```

### 学生への注意（署名していないため）

初回は「開発元を確認できません」と出ます。**右クリック（control＋クリック）→ 開く**、
または「システム設定 → プライバシーとセキュリティ → このまま開く」で開けます。

## 3. Grasshopper プラグインの配置先

初回セットアップ（`setup_runtime.py`）がフォルダを作成してからコピーします。
Grasshopper を一度も起動していなくても入ります。

| OS | 配置先 |
| --- | --- |
| Windows | `%APPDATA%\Grasshopper\Libraries\StbGrasshopper.gha` |
| Mac | `~/Library/Application Support/McNeel/Rhinoceros/8.0/Plug-ins/Grasshopper (b45a29b1-4343-4035-989e-044e8580d9cf)/Libraries/StbGrasshopper.gha` |

- Rhino 起動中はコピーに失敗することがあります。Rhino を終了して `Install_once`（Windows: `.bat` / Mac: `.command`）を再実行してください。
- Mac では検疫属性（quarantine）を自動で外します。

## 4. 起きたエラーと対策（再発防止メモ）

| 症状 | 原因 | 対策（実装済み） |
| --- | --- | --- |
| Windows: Setup.exe で「pip の更新に失敗しました」。手動実行では成功する | Inno Setup の **RedirectionGuard** が有効だと、`[Run]` から起動した `.venv\Scripts\python.exe` が `0xC00004BC`（STATUS_UNTRUSTED_MOUNT_POINT）で落ちる | `student/StructuralToolbox.iss` に `RedirectionGuard=no`（`PrivilegesRequired=lowest` なので影響なし） |
| Windows: 別の PC で「pip の更新に失敗しました」、`exit code 3221225477`（`0xC0000005`）で出力なし | その PC に別の Python（Anaconda など）があり、`PYTHONHOME` / `PYTHONPATH` がそちらを指している。`.venv\Scripts\python.exe` はこれらに従うため、別の標準ライブラリを読み込んで落ちる。ユーザーの site-packages（`%APPDATA%\Python\Python312`）が混ざることもある | `setup_runtime.py` は `PYTHON*` / `PIP_*` / `CONDA*` を除いた環境で pip を実行し、`PYTHONNOUSERSITE=1` を設定。起動用 `.bat` / `.command` と Grasshopper コンポーネントも同じ変数をクリアする |
| Windows / Mac: 古い `.gha` が同梱される | 既存のビルド成果物があると再ビルドしなかった | ビルドスクリプトが毎回 `dotnet build` する |
| Windows: Grasshopper 未起動の PC に `.gha` が入らない | Libraries フォルダが無いとスキップしていた | フォルダを作成してからコピー |
| Mac: `.gha` が Rhino に読まれない | 配置先が `~/Library/Application Support/Grasshopper/Libraries`（誤り） | Rhino 8 for Mac の正しいパス（上表）へ配置。アンインストールも対応 |
| Mac: `bash build_student_installer_mac.sh` で「build_student_mac.py がありません」 | そのスクリプトはリポジトリ全体が必要 | tar.gz と一緒に `make_pkg_YYYYMMDD.sh` を出力（postinstall 等を内蔵） |
| Mac: .pkg のインストールが失敗、`/tmp/stb-install.log` が空 | 「自分専用」の .pkg では postinstall がユーザー権限で動くのに、`sudo -u` を使っていた（パスワードを求めて失敗） | `student/mac/postinstall` を root / ユーザー両対応にし、出力を全部ログへ |
| Mac: 「ライブラリのインストールに失敗しました。wheels フォルダが壊れている可能性があります」 | Windows で macOS 用 wheels を集めると、環境判定で Mac 専用の **`uvloop`**（`uvicorn[standard]` の依存）がスキップされる | `student/fetch_wheels.py` で macOS 向けに `uvloop` を明示追加。失敗時は pip の実際のエラーも画面に表示 |

### wheels を入れ替えたとき

`student/dist/_cache/wheels/macos`（または `windows`）を削除してからビルドすると、確実に取り直します。

```powershell
Remove-Item student\dist\_cache\wheels\macos -Recurse -Force
.\student\build_student_mac.ps1
```
